# Job Portal

An ASP.NET Core MVC (.NET 8) web app started as a job portal.

## Current state

This repo is the initial scaffold. It has the standard MVC template pages (Home, Privacy, Error) with a single `HomeController`. Job listings, applications and user accounts have not been built yet.

## Tech stack

- ASP.NET Core MVC on .NET 8
- Razor views, Bootstrap and jQuery from the default template

## Run it

```bash
cd "Job portal"
dotnet run
```

Then open the URL printed in the terminal. You can also open `Job portal.sln` in Visual Studio and press F5.

## Planned features

- Job listings with search and filters
- Employer and candidate accounts
- Applications and status tracking
